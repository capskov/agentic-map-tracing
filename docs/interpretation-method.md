# Agent 影像判图方法

本页说明 Agentic Map Tracing 的工作思路。当前实际专业规则和现场经验集中在道路模块；其他地物需要各自的专业 Skill 与验证。本页不是已实现的多地物自动提取框架，也不描述新模型架构。

## Observe：先观察整个地物

确定任务口径、目标范围和路由，在能看清前后延续的尺度辨认地物。再到清晰断面查看局部。低分辨率影像看不清时，优先换观察范围和证据；无限放大不会恢复树下细节。

保留原始影像。适度对比度、低饱和或边缘提示可以帮助观察，但不能把处理产生的边缘当成新测量证据。来源、坐标、显示和真实宿主状态也须核实。

## Understand：解释对象及关系

在落点前说明看到的是什么：道路上的标线、铺装分界、路缘、树池、车身、阴影、裸土或屋檐，不能只说“这条亮边”。区分目标外缘与相邻地物的边界。

道路例子包括：车道边缘标线位于铺装内部；旁边可能还有路缘带或非机动车道；行道树可能位于步道/绿化条带；中分带实体结束后沥青可能连通。需要同时解释这些关系，不能分别画出几组互不相容的线。

车辆、围墙和出入口提供场景线索，不是绝对边界。车辆可能占土肩，围墙可能不平行，树冠也不能精确给出树干位置。证据发生冲突时，重新检查其对象语义和可靠性。

## Reason：用专业知识提出可反证的候选

把清晰可见边界、间接证据和遮挡推断分开。道路中，清晰标线高权重约束走向及车道组织，清晰铺装分界定位外缘；树影和周边对象辅助解释看不清的部分。

规则段两侧应共享走向和合理断面。低等级路规则段可优先提出等宽候选；较高等级道路须看标线、转向箭头、增减道及渠化。道路等级只是先验，不能据此凭空增加车道或强套宽度。

稳定断面的平行关系不能机械套给转角或真实渐变；对称也必须有支持。渠化可能在一侧或两侧发生，不能为了对称而违背清晰边界。分开正常段、渐变段、稳定展宽段与口门，候选应能解释观察到的连续变化。

典型车道尺寸只检验合理性，不能替代原图尺度。一次现场估计的宽度或半径不应成为全页默认值。

## Trace：让工具执行已解释的几何

记录原始像素及坐标约定，再交给工具做变换、法向宽度、相切过渡或宿主写入。两侧从共同道路带求出，分段接点来自同一组约束，不硬塞旧坐标掩盖失配。

原生读回、对象摘要和保存结果核对执行。工具不能通过把错误点算得更精确来改正语义误判。连接器缺失或能力受限时如实说明，不模拟成功。

## Verify：寻找能推翻候选的证据

先看长段两侧及周边布局，再核清晰断面、转角、树影前后和相邻连接。留出未参与拟合的清晰断面复看。人工参考应实际读取并解释其意图，不只校验图层保持不动。

真实 CAD/GIS 叠加与原图/候选对照分开保存。原生预览颜色或加载状态异常时另取实际窗口核查；换成 RGB 文件格式不等于恢复已经丢失的颜色。

反复整体偏移按三层排查：

1. 原始影像到宿主显示：引用、比例、旋转、裁切、视图和稳定地物。
2. 选定像素到实际对象：裁剪起点、倍率还原、半像素约定、行列方向和原生读回。
3. 候选到实际边界：共同中心、方向、宽度、道路组成和两侧残差。

两侧同向错位提示共同位置可能有误；相反错位提示宽度；沿程变化提示走向或曲率。它们是待验证的线索，不是自动诊断结论。

## Correct：记录改变了什么认识

保留旧候选、矛盾证据、修改理由和修后叠加。证据不足时标待核，不用平顺、循环次数或更宽的容差代替核查。连续失败应暂停扩大范围，先在失败样例上验证新方法。

最小记录可以回答六个问题：目标是什么？直接看到了什么？推测了什么？哪些证据冲突？为什么修改？还有什么不能确定？

人工反馈先更新其对应样例与适用条件，再抽象成可迁移规则。“学习”不意味着每条反馈自动变成所有场景的绝对要求，也不代表模型权重被训练。
