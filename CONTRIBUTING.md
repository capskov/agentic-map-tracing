# Contributing / 共同改进

Fork, modify, redistribute, and improve under the [MIT license](LICENSE), preserving its notice. Issues and pull requests are welcome. No CLA is required by this project.

欢迎改进Agent判读、提示、失败诊断、CAD/GIS适配、小型确定性工具和有依据的新地物Skill。优先解释为什么改变判断，不以庞大算法替代Agent的场景理解。

For a correction case include shareable imagery and permission/source, target semantics, failed candidate, contradictory evidence, revision, actual overlay, uncertainty and relevant agent/tool settings. Do not upload private engineering inputs, credentials or unlicensed imagery. Narrative-only cases are useful if marked as not independently reproducible.

Keep domain rules in their module. Preserve invocation names or document migration. Math/format checks do not establish visual accuracy; do not claim cross-model equivalence without evidence. Documentation edits need relevant link/metadata checks; script changes need targeted behavior checks; backend changes need scoped native evidence.
