# 判读试验与失败留证

用于反复错位后的局部重新试验。冻结旧图与旧参数，先无叠线看长段和道路组成，再读人工示教并解释其语义；提出少量相互可比较的候选，逐个用直接证据反证。不要把“换了模型/算力”当作精度已改善的证据。方法、提示和核查口径同时改变时，不属于受控模型对照。

## 两类本次有效的拦截

- 有清晰成组标线时，记录实际原始像素位置及各线语义，成对取中和方向，再核车道宽、路缘带与非机动车道。不能从一个受阴影影响的灰色总带重新猜中心后，自报残差接近零。旧验证标签也可能错；新证据推翻旧标签时，明确撤回旧结论。
- 人工图层须实际读取，区分示意、等宽关系、准确边界与未确定区域，不只校验它没被改。可见灰带在树下缩窄时，不能据此直接推翻人工长段示教。示教与新判读矛盾的候选应单列，核清依据后再推广；保留被否决的试画。

## 把道路带作为一个对象思考

用同一组走向、横断面和宽度变化描述两侧，明确正常段、渐变起终点、展宽后稳定段及口门。渐变宽度应按已识别的车道组织合理变化，不分别任意拉两条S形样条。分段接口须从同一个道路带求出，分别计算再硬塞旧端点会破坏约束。转角圆弧单独核对铺装/绿地两侧关系，圆滑不等于位置正确。

## 小工具只整理证据

可用 `scripts/evidence_strips.py` 按原始行或列导出带坐标条带和元数据，减少裁剪缩放还原错误。例如：

```text
python scripts/evidence_strips.py --image source.tif --output evidence.png --axis row --positions 100,140,180 --start 200 --end 320
```

条带必须与无叠线长图一起看。工具不识别道路、不把最强亮度峰自动当路缘、不验收线位；漆线、路缘、车身与树影均可能形成峰。先写语义再读坐标，未参与拟合的断面可作留出复看，但它们仍不是测量真值。用两边偏差和清晰/遮挡状态分别报告，不能把小数点位数当精度。

## 宿主截图保真检查

原生预览PNG可能是颜色很少的P模式调色板图，即使图片尺寸很大也会明显抖色，影响沥青、步道与阴影判读。记录图像模式/颜色数量，与原图及实际窗口截图比较；重新转换为RGB不会恢复已丢失颜色。此类预览可证明对象出现，但不宜单独承担颜色边界判断。实际窗口图与原生预览分别留证，使用可用的窗口截图工具并遵循其技能；不能将显示质量问题自动解释成CAD坐标整体偏移。

## 交付边界

提供同范围修前/修后实际窗口、候选理由、否决理由、原生读回/保存、人工和认可对象保护记录。用户审阅后再决定哪些规则有效；单页两口试验不能证明模型强弱或技能成熟。可公开包仅含通用方法和工具，工程证据留在本地。
