# 逐口审阅与错误诊断

为每处保留：编号与共享路口组、原图范围/像素点、边界口径、直段宽度/扩口、可见段及推测段、理由、原图对照、真实宿主叠加、修正事项、原生对象身份、保存核验、用户审阅状态。

有用的纠错信号：

|现象|先查什么|改正后的证据|
|---|---|---|
|每处像印刷套色一样偏同一方向|裁剪原点、标题留白、显示倍率、像素中心、引用变换|至少两个远距离特征的残差与局部叠加|
|宽度突然变大，边线贴着土色带|是否把裸地/土肩当铺装|远处无遮挡路段与硬化外缘|
|树影处随亮斑收窄或无依据变宽|是否追树冠/可见白色而非路缘|遮挡两端切向与合理连续宽度|
|一边贴路另一边偏离|中心、宽度及两边独立猜测|共享中心、法向距离和两边叠加|
|局部灰线弯来弯去，长路整体却是直的|过度跟随树影间亮斑，缺少长段走向假设|远端入口/围墙与多个间隔横断面支持的共同走向|
|停放车辆旁只剩一条窄带被描成道路|把可通行净空当铺装总宽|车身、车影、停车占用与远端边缘的综合解释|
|小入口线压在屋檐上|候选中心和道路对象选错|细像素格及房间通道连续关系|
|边线沿沟渠/水面走|把沟边/桥头扩口当路边|铺装或桥板两边及远处延续|
|交叉口中间出现贯通路缘|把支路截面当整个交叉口拓扑|道路开口保留，转角在实边界终止|
|多次截图内容相同|目标文档、相机、加载时序|独立范围读回与不同地物画面|

这类问题已有现场实例支持，但并非所有道路的固定规则。例如窄路确实可能局部变宽；应凭图像解释，而不是为了满足等宽消除真实变化。

## 人工长段示教后的调整

两处现场人工示教用约百米的平行线表达连续道路，暴露出此前“只围绕穿越点裁剪、追随局部亮色带”的局限。一处候选偏窄并略弯，另一处局部拐向了树冠间的亮斑。长段方向、远端院门、车辆停放及多处边缘的共同解释，比单个局部明暗跳变更可靠。

新的顺序是：长段概览与候选走向 → 远处清晰横断面及停车关系 → 共同中心与等宽候选 → 局部验证/反证 → 独立处理真实口门 → CAD叠加。不要倒过来先追亮斑，再靠几何平滑掩盖对象选错。人工提供的宽度只适用于该示例，不写成所有道路的通用宽度。

## 当前验证边界

该技能初稿来自单个工程页19处候选的迭代，包含清晰弯道、窄入口、树荫、十字口与桥头。已有部分样例经用户认可或人工示教，后续又完成过沿真实路由逐段复扫、补漏及整页原生叠加复核；各区间认可状态分别记录，局部认可不代表整页验收；没有独立测量真值，也未证明跨影像来源的识别精度。

本包只保留抽象经验和自制几何夹具，不含工程影像、实际坐标或CAD会话。数学自检只验证运算，不能冒充独立视觉识别评测。公开发布前应优先补充来自不同分辨率/道路类型的可公开样例，并将可见边界与遮挡推断分别评估。

## 共同中心选偏的现场教训

一例两侧等宽线都向同一侧偏移，影像与宿主截图本身却基本对齐。原因是候选中心在原始影像上就已选偏，等宽生成把同一错误传给两侧；仅做几何读回和影像配准无法发现它。修正应重新用多个清晰断面的两侧材质过渡约束共同中心，再重算等宽边线与扩口。偏差随位置变化时同时调整走向，不把所有偏差当固定平移。

省算力的检查点是落图前的同范围“无叠线原图／旧候选／新候选”并排对照，以及前中后几个断面的带方向残差。边界人工估计要注明不确定性；不要用同一生成公式与同一候选中心自证贴边。分别报告影像显示配准、选点到对象落线、对象到实际边界三个误差，前一层通过不能代替后一层通过。

## 防止“宏观合理但整体漂移”的验收漏洞

宏观判断用于提出道路走向和组成假设，不能直接产生未经局部确认的最终坐标。先在无叠线原图中选定可解释的清晰边界锚点，注明其对象语义与原始像素；再生成线，在真实宿主中对照这些锚点。两侧前中后均须有核查，不能只看缩略全景是否好看，不能用同一组主观猜点再次充当独立验证。锚点被树挡住时选择相邻清晰断面，不将推测段算作压边通过。

每个可见边界记录“实物是什么、哪里结束、何处与另一面连通”。绿化分隔岛边线只沿实体岛轮廓，端部须收合；岛结束后的相连沥青上不得按推定中分带继续画路缘。标线、导流线与材质界线分开，不因图形连续性好看而制造实际不存在的边界。

优先修失效的判据：共同中心选错、局部切线过长、道路组成误判、忽略实体端点；几何平顺和对象读回另验。连续多处失败时暂停批量推广，先用失败样例复核新方法；不靠扩大允许误差宣布通过。

方法参考：Topo-boundary（Xu、Sun、Liu，2021，https://arxiv.org/abs/2103.17119）把道路边界检测和连通性作为评估对象。这里借鉴其区分位置与连通性的思路，未安装、训练或验证该论文模型，不能声称其精度已用于当前影像。

## 成对道路带与有限分辨率：必须执行的失效检查

位置验收把两侧作为一个道路带，同时看其相对标线、连续材质界线、树列及建筑的位置；不能先逐条接受一条边线，再孤立接受另一条。至少记录成对残差及共同中心：两侧同向表示中心可能错位，两侧相反表示宽度可能有误，沿程变化表示走向/曲率可能错误。单幅车行道、两幅车行道和分隔岛要在同一幅宏观对照中相互解释，不能分别目估三组控制点后仅检查是否平顺。

宏观粗错优先在能容纳长段走向及两侧背景的尺度核查，不无限放大低分辨率影像。放大只用于追查坐标或确认原有像素，不会产生真实细节。需要辅助时保留原图，另出低饱和、适度对比度增强与边缘提示，同范围并排查看；滤镜边缘包含树影、屋檐等伪边缘，不自动选作路缘，也不将锐化结果当新增测量证据。

优先实证追踪选点—生成—原生读回—显示链。若原图候选已经进入建筑且生成与现场读回一致，应把该实例归入上游选点失败，不能含混归因算力或注意力。显示配准另有亚像素残差时分别列出，不宣称全部系统误差为零。未经压边核查的固定步道外偏只是推测，不用其落在树影内来证明车行道边线错误，也不能以图层用途解释来掩盖真实错位。


局部试验获得人工效果认可后，扩大范围时记录认可区间、保留其共同中轴和断面约束；延伸到弯道出口须另看长段切向，不无限外推原圆弧。路口渐变和支路扩口独立接入同一主路，不恢复旧的未核中轴。局部认可不是其他断面尺寸、步道或全页验收的授权证明。
